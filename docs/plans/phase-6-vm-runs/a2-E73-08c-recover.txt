== recover --yes
`recover` puts normal Windows back on this PC. It will:
  - stop the Rulebox Agent service (if it runs)
  - restore AutoAdminLogon
  - restore DefaultUserName
  - remove DisableAutomaticRestartSignOn (it did not exist before Rulebox)
  - remove EnableFirstLogonAnimation (it did not exist before Rulebox)
  - remove DisablePrivacyExperience (it did not exist before Rulebox)
  - delete the automatic sign-in password secret
  - delete the pending Staff password secret
  - remove the Rulebox shell and lock policy from the RuleboxStaff account
  - mark the kiosk as disabled in the agent state
  - keep the kiosk off until the next enroll (recovered.flag)
