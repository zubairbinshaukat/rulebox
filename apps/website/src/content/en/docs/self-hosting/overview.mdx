Rulebox's own code is MIT-licensed. You may run the whole system yourself, including commercially.

## What you need today

The backend runs on [Convex](https://www.convex.dev/). Self-hosting today means running your own Convex deployment and pointing the dashboard and the agent at it.

An on-premises, air-gapped install is not offered.

## Planned

A one-command setup for self-hosting is planned.

> The step-by-step guide will be published here. Until then, the repository README and the contributing guide describe how to run each part.
