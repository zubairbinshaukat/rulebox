This page summarises the design. The full threat model will be published in these docs.

## What we defend against

- Staff escaping the desktop.
- Tampering with the agent.
- One person reading another's data.
- A compromised dashboard account.
- A stolen enrolment code.
- A network attacker.

## Layers on the PC

Standard user, approved programs only, policy restrictions, a protected service, and a process watchdog.

## Trust in what we send

TLS for every connection. SHA-256 on every installer. Policies signed with your organisation's key; a PC rejects anything with a bad signature. An optional publisher check for installers. Short-lived enrolment codes that you can revoke.

## Known limits

- Desktop apps with their own file dialogs can still browse outside a person's folder in v1.
- Physical attacks need a BIOS password and BitLocker, which you set up.
- An out-of-support Windows is still at risk.
