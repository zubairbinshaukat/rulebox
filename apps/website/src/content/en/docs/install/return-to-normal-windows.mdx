Rulebox is never a one-way door. Turn kiosk mode off and the PC behaves like normal Windows. Rulebox restores the settings it changed.

## From the dashboard

Turn kiosk mode off for the PC in the dashboard.

## At the PC

Use the hidden admin exit: a key combination and a PIN. Every use is written to the audit log.

## Uninstall

Uninstalling restores the normal Windows shell.

## Recovery

Hold Shift at start-up to reach the Windows sign-in screen.
